# 独立扩展分发维护设计

日期：2026-09-30。范围：仅 `feature/standalone-extension`，不合并到 `main`。

## 目标与取舍

本轮先完善现有安装渠道，准备 1.1.1；不制作安装引导网站。用户已报告同学可以通过 Edge 商店、无需 VPN 安装。该报告仅证明一次安装成功，不代表所有网络可用或真实课程 PDF 已通过验收。

可选路径：只更新文档最省事，但无法补齐扩展语言元数据；同时做全部浏览器上架与更多格式范围过大。因此采用小版本维护：补语言元数据、修正文档、准备 Firefox 提交材料。图片和纯文本预览在下一轮单独设计；其他学校、阅读器切换、Office 不在本轮。

## 已知状态与搜索问题

- Edge 正式安装地址：https://microsoftedge.microsoft.com/addons/detail/ibgcgppobifaogaodeimafhpmoonioch
- 用户报告“复旦”“eLearning”、完整中文名称等关键词无法搜到。尚未确认原因；索引延迟、地区或语言差异仅为待验证假设。
- 当前构建直接写入中文名称和说明，没有 `default_locale` 和 `_locales`。
- 现有商店材料仍写“尚未上架”，需要纠正。Firefox ZIP 是未签名测试包，不能宣传为普通用户永久安装渠道。
- 已发布的 1.1.0 Release、标签及附件保持不变。

## 改动边界

### 1. 包内语言元数据

在 `extension/_locales/zh_CN/messages.json` 和 `extension/_locales/en/messages.json` 定义名称、简短说明和工具栏标题；构建清单使用消息引用，默认语言为 `zh_CN`。英文名称使用 `Fudan eLearning PDF Preview`。这是安装元数据本地化，不宣称阅读器和帮助界面已完整英文化。

复用现有 Chromium/Firefox 构建，不改网站权限、后台请求处理或 PDF 阅读流程。缺失消息或无效清单应在测试中失败，不让错误包进入提交阶段。版本升为 1.1.1，保留 Firefox 扩展标识和 Edge 原产品。

### 2. 商店材料与说明

整理简体中文、英文商店介绍；自然包含“复旦 / Fudan / eLearning / PDF”等准确关键词，不堆砌无关词或冒充官方。商店语言配置和包内语言配置分开记录，不能声称前者会随构建自动更新。

README、现有帮助页、商店材料、验证记录和路线图同步事实：Edge 已上架；直达链接为当前可靠的分享入口；搜索不可见尚待查明；记录同学无 VPN 安装为用户反馈。说明安装后刷新课程页面、登录有效账号、停用重复油猴脚本，以及 Firefox 未签名 ZIP 的限制。

保留油猴版与独立扩展版的分支导航，不改变 `main`。路线图改为先安装分发、再图片与纯文本、随后其他学校及阅读器选项。

### 3. Firefox 提交准备

准备独立清单：版本与固定 ID、包校验值、源码与锁文件、构建步骤、依赖许可证、权限/数据使用说明、静态检查警告解释、无账号演示路径和支持/隐私链接。隐私链接指向扩展分支，截图只用演示文件。

提交前重新运行 Firefox 静态检查；所有警告如实记录。账号登录、法律声明、签名申请和正式商店提交需要所有者确认；本轮准备材料不等同于签名完成或审核通过。不得索取、保存或分享学校账号。

## 验证与验收

1. 自动测试验证两种语言的 JSON、全部消息引用、默认语言及两个浏览器清单；无新增默认权限。
2. 运行现有测试、静态检查、双浏览器构建及包校验；检查语言文件进入 ZIP，排除 iCloud 重复文件。
3. 尽环境所能回归现有浏览器演示与链接处理；不能运行的检查明确标注未执行。元数据英文显示不等于整套界面英文验收。
4. 搜索调查记录日期、关键词、页面语言/地区及实际观察；无法访问时记录受限，不根据页面 URL 推断结果。调查不阻塞本地修正，也不将搜索可见作为可保证的验收项。
5. 本地包、商店草稿、正式提交、审核通过分开报告。任何新 Release 或商店发布保持原版本可追溯，不覆盖 1.1.0。

## 自查

本设计仅覆盖分发维护；不更改 PDF 数据流、不增加服务器、不上传课程文件。已区分用户反馈、已有测试、待调查现象及计划功能；无引导页、跨学校或多格式实现混入本轮。
