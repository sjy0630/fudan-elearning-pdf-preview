# 图片与纯文本预览设计

日期：2026-09-30。用户已同意在现有独立扩展中加入本地图片、纯文本阅读器；本文把已同意的方案细化为实现和验收边界，待书面复核后进入实现计划。

## 目标与范围

推动“支持更多文件类型”的愿景，同时保持无需油猴、无需第三方在线转换的安装和阅读体验。仅修改 `feature/standalone-extension`；不修改油猴主分支、不操作 Edge 审核、不覆盖 1.1.1 安装包。实现阶段版本升为 1.2.0，候选通过验证不等于发布。

支持 PNG、JPEG（.jpg/.jpeg）、WebP；支持 TXT、CSV、LOG、JSON、XML、YAML（.yaml/.yml）、以及 .c/.h/.cpp/.hpp/.py/.js/.ts/.java/.css/.sql/.sh 代码文件的纯文本展示。扩展名大小写不敏感。代码不执行，CSV 不转换表格，XML 不解析实体。暂不加入 SVG、HTML、Markdown 渲染、Office、压缩包、音视频或在线转换。其他学校和 PDF 阅读器选择仍是后续独立迭代，不因本轮结束而视为完成。

## 方案取舍

采用按格式分派的本地阅读器：复用来源验证、登录请求与精确授权，PDF 继续使用 PDF.js，图片交给浏览器图像解码，文本以文字节点显示。

第三方预览服务可能要求上传私有课件或外部网络访问，不采用。统一转换成 PDF 会增加依赖、等待时间并损失文本操作体验，不采用。此次无需额外运行时依赖。

## 模块与数据流

1. `catalog.js` 登记格式 ID、扩展名、阅读页面，不增加学校域名。格式判定集中在核心模块，避免内容脚本、后台、阅读器各写一套规则。
2. `core.js` 将文件名清理与 PDF 后缀补齐分开；保留 PDF 兼容入口。只处理受支持学校的 Canvas 文件链接或支持格式的直接文件路径。优先使用明确文件名，无法从文件名识别时再检查 URL 路径；不得把任意文本中的 `.txt` 片段当作文件名。未知格式不拦截。
3. 内容脚本发送统一 `open-file` 消息；后台再次校验发送者、来源、格式和文件名，按受信任目录分派阅读页面。保留 `open-pdf` 兼容路径，拒绝未知格式或名称与格式矛盾的消息。不能由消息指定任意阅读器 URL。
4. 从 `reader.mjs` 抽出通用受限读取函数，保留 `readPdf` 包装与既有 PDF 行为。共享权限检查、重定向权限提示、流式大小限制、超时和清理机制。格式校验独立于网络读取，能够用固定字节样例测试。
5. 新增本地图片/文本阅读页面，不把非 PDF 交给 PDF.js。接收受验证来源和格式，取得字节后校验并显示；下载使用原始字节，不下载重新编码的文本。查询参数也必须重新校验，不能绕过格式或域名限制。

正常下载控件、修饰键点击、右键和未知格式维持网站原行为。课程原有 Canvas 图片预览是否被打开不影响显式下载入口；本扩展仅处理符合既有链接规则的普通文件名点击。

## 文件验证和资源上限

- PDF：维持现有 100 MiB 上限及 `%PDF-` 检查，不放宽现有默认权限。
- 图片：最多 20 MiB；验证 PNG、JPEG、WebP 文件签名及对应类型，不能只相信扩展名或服务器 MIME。读取头部尺寸并拒绝超过 4000 万像素、单边超过 16384 像素、缺失或无效尺寸的文件，再交给浏览器解码。损坏或解码失败显示错误，不自动降级为网页。WebP 动画首版不支持，检测到动画标记时明确提示下载阅读。
- 文本：最多 2 MiB；默认严格 UTF-8（含 BOM），识别带 BOM 的 UTF-16 LE/BE；另提供用户主动选择 GB18030 或 UTF-8 的编码选项，不静默猜测替换乱码。解码后拒绝 NUL 等不应出现的二进制控制字符（允许制表符、换行、回车）；编码失败给出切换编码或下载提示。
- MIME 用于辅助拒绝明显错误响应。允许缺失或通用二进制 MIME，但必须通过对应字节检查。拒绝服务器返回的 HTML 登录页；HTML MIME 或解码后以 HTML 文档/表单结构开头的内容作为疑似登录响应提示，不执行其中内容。代码文本中普通 `<script>` 字符串必须安全作为文本显示，而非被当作可执行 HTML。
- 所有上限均检查声明长度和实际流式累计长度；超限取消读取，提示准确的格式上限。沿用 60 秒读取超时；失败、重试、离开页面都清理事件监听、计时器和对象 URL。旧请求不得覆盖新请求的显示结果。

## 使用体验

沿用现有顶部操作栏，不新建安装引导网站。

图片提供缩放、适应窗口、按 90 度旋转、下载、打开原文件。旋转后重新计算适应尺寸；宽高极端图片不能撑坏工具栏。文本提供自动换行开关、编码选择、复制全文、下载、打开原文件；复制失败说明可手动选择复制，不申请持久剪贴板权限。文本用 `textContent` 显示，不用 `innerHTML`、iframe 或外部渲染服务。

统一显示加载中、无权限、登录过期、格式不匹配、超限、损坏和网络错误；读取失败保留安全的原文件入口。新控件有中文标签、键盘焦点、可读状态提示。初始未加载时禁用内容操作。

加入随扩展打包的生成图片和文本示例，在现有帮助页提供入口，不包含真实课件。无账号可体验，但不将示例成功宣称为学校集成成功。示例入口只映射固定内置资源，不能接受任意资源路径。

## 权限与分发

默认权限仍为 `webRequest` 与复旦网站，重定向仍仅按实际目标 HTTPS 域名由用户授权；不新增 `tabs`、剪贴板、全站默认权限，不加入遥测、第三方上传、CDN 或远程代码。扩展 ID 保持不变，商店名称本轮不改；帮助和描述在功能验证后准确说明支持范围。新版本只构建为候选，发布及商店更新另行处理。

## 验证与验收

1. 单元测试覆盖所有支持后缀、大小写、URL 回退、错误格式、伪造消息、恶意来源、文件名保留，以及下载控件和修饰键不拦截。
2. 网络测试覆盖登录失败、HTML 响应、缺失/通用/冲突 MIME、声明及流式超限、空内容、超时、精确授权和监听器清理；保留既有 PDF 测试。
3. 格式测试覆盖三种图片签名与尺寸、伪装图片、损坏头部、超大尺寸、动画 WebP；文本覆盖中英文、BOM、GB18030 手动解码、无效编码、二进制和 HTML/脚本字符串不执行。
4. 浏览器测试在隔离 Chromium、Edge、Firefox 中验证图片加载/缩放/旋转/适应、文本显示/换行/编码/复制或明确失败反馈、下载字节保持原样、错误提示及示例离线读取。模拟 Canvas 点击流程必须覆盖新格式分派和原 PDF 回归，记录浏览器版本与实际结果。
5. 执行全套单元测试、语法检查、双浏览器构建、安装包验证，再串行执行浏览器测试，禁止在浏览器测试期间重建安装目录。验证新文件进入包、未引入远程代码及默认权限扩大；环境无法完成的检查明确标记，不以模拟结果代替真实学校或其他系统的验证。
6. 只报告有证据的兼容范围；不承诺其他学校、原生 PDF 阅读器、Office 或商店审批完成。
