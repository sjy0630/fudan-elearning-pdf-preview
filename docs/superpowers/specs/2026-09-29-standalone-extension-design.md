# 独立 PDF 预览扩展

用户目标是免装 Tampermonkey，并让同学能方便安装。保留原用户脚本，新增 Chrome/Edge Manifest V3 和 Firefox Manifest V3 扩展，共享业务代码。商店审核完成后的安装链接是面向普通用户的主要分发方式；本地 ZIP 仅为提前体验及商店提交材料，不能描述为一键安装。

点击 eLearning 内的 PDF 文件名，在扩展的新标签页打开自带 PDF.js 阅读器。新标签页避免学校页面的 iframe 限制，PDF.js 避免依赖浏览器原生 PDF 设置。提供翻页、页码跳转、缩放、适合宽度、文本选择、下载及打开原文件。默认不保存到下载目录。文件只在用户浏览器中处理。

content.js 仅识别本站 PDF 链接；background.js 校验来自本站的消息再创建阅读器标签页；viewer.mjs 再次校验来源 URL，使用当前浏览器登录状态读取 PDF。默认主机权限仅为 elearning.fudan.edu.cn。webRequest 仅用来识别本次文件请求的重定向；若跨站读取需要额外权限，阅读器显示目标域名并在用户点击后只申请该域名。HTTPS 通配符只出现在可选主机权限中。

PDF.js 的代码、worker、字体、CMap 和 WASM 随扩展打包，不加载远程代码；关闭动态表达式求值。限制单个文件 100 MiB，读取超时 60 秒，检查 PDF 签名。登录失效、非 PDF、大文件、读取失败均显示可操作的错误信息。

验证包括 URL/消息权限边界、下载按钮和快捷点击保留、重定向权限流程、实际 PDF 页面的渲染与翻页，以及两份打包清单。Chrome/Edge 共用包；Firefox 包采用后台脚本和独立扩展 ID。未实测的浏览器不得标记为已通过。
