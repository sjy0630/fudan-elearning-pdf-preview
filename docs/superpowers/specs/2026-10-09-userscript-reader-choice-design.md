# 油猴版 PDF 阅读器选择设计

日期：2026-10-09。用户已选择先做油猴版，并确认细化方案：“确认，按此方案实施”。批准内容包括默认原生、随脚本打包的 PDF.js、新增偏好存储权限、切换不重新下载、失败手动回退及不扩大联网范围。本文是已批准的实现规格，不表示功能已经实现。

## 范围和取舍

先完成当前图片与文本预览迭代，再为油猴版增加阅读器选择。保留一个可直接安装的 `.user.js`，不要求使用者另装扩展、启动本地服务器或配置阅读器地址。暂不接入自定义在线阅读器，不同步开发扩展版的切换功能，不推进上架或其他学校适配。

选择自带阅读器与本地 PDF.js 的组合：前者保持现有习惯，后者提供跨浏览器较一致的页内阅读体验。在线阅读器可能依赖外网并暴露私有课件；仅提供“在新标签页打开”不能满足真正更换阅读器的目标，均不作为本轮替代方案。

## 用户行为

- PDF 弹窗增加有中文标签的“阅读器”选择：浏览器自带、内置 PDF.js。图片和文本不显示此选项。
- 首次默认浏览器自带，保持升级后的现有行为；以后优先使用记住的选择。
- 使用油猴存储 API 保存阅读器 ID，仅新增对应读写存储权限，不扩大网站范围。存储失败时在当前页面保留选择，并提示无法永久保存；未知历史值回退到浏览器自带。
- 切换复用已验证的文件字节，不重新请求学校文件，不触发自动下载。首次切换到 PDF.js 从第 1 页开始；暂不承诺同步原生阅读器的页码和缩放，因为无法可靠读取它的内部状态。
- PDF.js 提供上一页/下一页、页码跳转、缩放、适合宽度和可选中文字。两种模式共享关闭、原文件和原字节下载操作。
- 加密 PDF 在 PDF.js 中可输入密码重试或取消，密码不保存。原生模式的密码操作由浏览器负责。第一版不加入批注、编辑、表单填写、OCR 或全文搜索。

## 模块与打包

保留现有格式识别、学校请求和大小限制；增加偏好模块、统一阅读器生命周期接口，以及原生/PDF.js 两个适配器。适配器只接收已验证字节和取消信号，不能自行读取任意远程地址。

PDF.js 使用仓库锁定版本，维护者在构建时将核心代码、worker、需要的字体/CMap/解码资源及许可证合入安装脚本。不得加入运行时 CDN、`@require` 或远程可执行资源。资源表仅允许已打包的固定名字，拒绝未知路径。沿用 PDF.js 6.3.289 的 `BinaryDataFactory` 接口从本地资源表取得数据，关闭 worker 的网络资源读取；实施时以真实渲染测试验证资源供应完整性。

核心代码构建为可在用户脚本隔离环境调用的模块；worker 由内置代码创建对象 URL。禁用 PDF 内容脚本执行及求值支持。不以远程脚本或修改站点安全策略绕过 CSP。脚本体积会增加，构建结果须记录确切体积，不能用开发依赖大小代替实际安装文件大小。

## 生命周期和错误处理

控制器持有原始字节；给 PDF.js 的数据使用独立副本，避免 worker 转移数组缓冲后破坏下载或再次切换。每次切换、打开新文件和关闭弹窗均递增代次，取消渲染任务、销毁 PDF 文档和 worker、释放对象 URL；旧回调不能覆盖新阅读器。偏好只保存用户选择，不保存文档、密码或课程地址。

若 PDF.js 初始化、worker、字体或渲染失败，显示具体可理解的错误并保留“切换到浏览器自带”与“打开原文件”。不静默更改已保存偏好，不把失败内容上传在线服务。浏览器原生嵌入不能可靠报告是否已显示 PDF，不能仅凭 iframe load 事件宣称实际渲染成功。

## 验证与交付

1. 单元测试先覆盖偏好读写/异常/未知值、切换不重复请求、buffer 未被转移破坏、取消和过期回调、下载原字节及本地资源白名单。
2. 隔离 Chromium 和 Firefox 测试真实有效的多页 PDF：两种选择入口、PDF.js 页面绘制和文字层、翻页/缩放、切换/重开、刷新恢复偏好、下载与资源释放。无效 PDF 占位内容不能算渲染证据。
3. 验证中文字体、加密/错误密码/取消、损坏文件、超限、worker/CSP 失败及手动回退；文件读取完成后阻断外网，确认 PDF.js 不产生第三方请求。
4. 回归图片、文本和普通下载入口；检查构建可复现、许可证、无远程执行代码，记录最终脚本大小。
5. 必须区分页面注入/mock 存储与真实 Tampermonkey。真实管理器的安装、升级、权限提示、沙箱和站点 CSP 尚需单独验证；无法完成时明确列为发布前缺口，不声称全部兼容。
6. 保持油猴与扩展分支独立，不合并扩展到 main，不自动推送、发布或更新用户已安装脚本。阅读器版本号在实施计划中依据已交付版本确定。

## 自查

此方案只交付两种阅读器的选择和基本阅读，不将当前两版分别固定使用不同阅读器算作完成。体积、真实管理器兼容与 CSP 均需实测；失败时有明确本地回退，不扩大为在线预览或分发项目。
