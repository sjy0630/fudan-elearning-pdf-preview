# 油猴版路线图

本分支是 1.1.0 多格式预览的本地未发布候选；油猴版与独立扩展版继续分开维护。

1. 完成多格式迭代：保留已验证的 PDF、图片、文本预览，核对单文件构建与文档；发布前补真实 Tampermonkey 安装/升级、学校课程文件与实际 CDN 测试。
2. 用户复核[阅读器选择设计](superpowers/specs/2026-10-09-userscript-reader-choice-design.md)后，为油猴版实现“浏览器自带 + 本地内置 PDF.js”的阅读器选择并保存偏好。继续单文件安装，不上传课件，不使用运行时 CDN。当前尚未实现。
3. 分发、上架及推广工作暂缓，需后续单独安排。本轮不推进其他学校适配，也不合并扩展版到 main。
