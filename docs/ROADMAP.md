# 油猴版路线图

本分支是 1.2.0 阅读器切换的本地未发布候选；油猴版与独立扩展版继续分开维护。已保留 1.1.0 多格式分支，不改动主分支或扩展分支。

1. 多格式本地候选已完成独立分支交付、干净源码重建、基础真实管理器测试、手动编辑升级和有效 PDF 原生显示/原字节下载。发布前仍需补自动升级、普通安装重启、真实学校课程/CSP、实际 CDN 与成功的 GM 跨站读取。隔离管理器重启要求重新审核脚本，不能算无条件执行通过；测试仅覆盖 Tampermonkey 5.5.0 / Chrome for Testing 155 的合成页面，不能扩大为所有用户环境。
2. `feature/userscript-reader-choice` 已实现“浏览器自带 + 本地内置 PDF.js”的阅读器选择、偏好保存、基本阅读操作及错误回退，继续单文件安装，不上传课件、不使用运行时 CDN。具体证据和边界见[阅读器验证记录](READER-VALIDATION.md)。正式发布前仍需在真实课程环境试用，并补普通安装/更新来源、重启与其他管理器的验证；这不是已发布版本。
3. 分发、上架及推广工作暂缓，需后续单独安排。本轮不推进其他学校适配，也不合并扩展版到 main。
