# Canvas 文件预览扩展：产品方向

用户于 2026-10-09 更新愿景：允许选择 PDF 阅读器、支持更多文件类型；免油猴和面向非技术用户的简易分发先延后。其他学校适配已从当前目标移除，不继续按旧路线推进。

## 当前版本

独立 WebExtension；复旦 eLearning 是首个适配平台；PDF 是首个文件类型。学校、文件类型和阅读器在 `extension/catalog.js` 分开登记。内容脚本和后台只依赖统一文件描述，平台适配负责识别 Canvas 文件地址。构建时由学校配置生成注入范围和默认权限。

扩展的 PDF 当前统一使用内置 PDF.js，用户脚本的 PDF 使用浏览器原生阅读器；这不是“用户可切换阅读器”的实现。两版继续独立维护。内置资源无需外部 CDN，不上传课程文件到第三方。

扩展分支已有 1.2.0 图片与文本候选实现（提交 `e8361dc`）；2026-09-30 隔离浏览器及模拟课程测试中，Chromium、Edge、Firefox 各通过 20 项检查。该历史证据不代表真实学校集成或商店发布。油猴版相同格式的适配于中断后继续，目前未完成；不覆盖已发布的旧版本。

## 推进顺序与验收

1. **完成已批准的图片与纯文本迭代。** 接续油猴版未完成的测试与实现，使两版都能预览 PNG/JPEG/WebP、文本及代码文件。遵守已批准的签名、尺寸、编码和大小检查，失败时保留原文件入口；分别记录运行环境和真实油猴管理器尚未验证的部分。
2. **PDF 阅读器选择。** 下一功能阶段明确选择入口、可选阅读器、偏好保存与失败回退，再实施。优先评估浏览器原生和本地内置阅读器；不下载远程可执行插件，不默认把私有课件发送给在线服务。密码文件、文字选择、下载和可访问性需按选项验证，不能用现有两个版本各自固定一种阅读器代替可切换功能。
3. **免油猴与简易分发：延后。** 保留已有扩展成果和安装渠道，但本轮不继续 Edge 搜索调查、Firefox 上架、安装引导页或商店更新。2026-09-30 曾确认 Edge 1.1.1 已提交审核；该记录不是当前审批结果，不在本轮重新查询。

当前不新增落地页、Office 或其他学校适配；Markdown、音视频等扩展格式仍需另行确定范围。阅读器切换是待实现目标，不是当前兼容性承诺。

## 架构边界

- 平台：域名许可、Canvas 链接识别、文件定位与登录要求。
- 文件：规范化后的来源 URL、文件名、格式及读取结果。
- 阅读器：只负责所支持格式的展示和用户偏好。
- 分发：浏览器清单、商店签名、离线资源、升级路径与安装帮助。

以实际文件预览与错误恢复的验证为准，区分源码候选、测试通过与正式发布。不要恢复已延后的分发任务或重新加入已移除的跨学校目标。
