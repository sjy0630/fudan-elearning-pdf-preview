# 项目路线图

2026-10-29：1.4.0 开发候选同步接入 PPTX 和旧版 PPT 的本地静态预览，提供翻页、跳页、缩放和适应窗口。原创双格式样例通过 Chromium / Firefox 两版界面的隔离检查；真实课程、管理器安装、商店分发仍待后续验证。本轮不推送或上架，详情见 [1.4.0 记录](releases/v1.4.0-candidate.md)。

main 集中维护油猴版与独立扩展的源码，两套安装入口继续分别维护；开发历史保留在相应分支。油猴版 1.2.0 增加阅读器切换；扩展源码 1.2.0 增加图片和文本，不自动改变商店发布状态。

2026-10-24：DOCX 已完成油猴、扩展源码接入及 1.3.0 打包，并按用户授权提交 Edge，后台显示 In review；商店仍为 1.1.1 Live。用户要求停止测试，本轮只做实现、静态核对、构建和提审，没有运行功能测试，也未推送或合并 GitHub、发布 Release。2026-10-13 的历史状态见[愿景推进核对](status/status-2026-10-13.md)。

1. 多格式本地候选已完成独立分支交付、干净源码重建、基础真实管理器测试、手动编辑升级和有效 PDF 原生显示/原字节下载。发布前仍需补自动升级、普通安装重启、真实学校课程/CSP、实际 CDN 与成功的 GM 跨站读取。隔离管理器重启要求重新审核脚本，不能算无条件执行通过；测试仅覆盖 Tampermonkey 5.5.0 / Chrome for Testing 155 的合成页面，不能扩大为所有用户环境。
2. 油猴版已实现“浏览器自带 + 本地内置 PDF.js”的阅读器选择、偏好保存、基本阅读操作及错误回退，继续单文件安装，不上传课件、不使用运行时 CDN。具体证据和边界见[阅读器验证记录](READER-VALIDATION.md)。后续补充真实课程试用、普通安装/更新来源、重启与其他管理器的验证。
3. 独立扩展的安装说明见[扩展版](EXTENSION.md)。DOCX 只提供本地内容阅读；PPT/PPTX 静态预览见 1.4.0 候选，尚未分发到商店。其他学校适配、XLSX 和扩展阅读器选择仍属后续工作。Edge 审核状态以上次查询记录为准。
