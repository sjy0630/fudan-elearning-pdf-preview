## 已知边界

- 中文样例没有嵌入 CJK 字体，显示依赖系统的中文字体回退；包含 CMap 不等于打包了所有语言字形。
- PDF.js 在 `useWorkerFetch:false` 时关闭其 ICC WASM 转换，使用自己的回退色彩转换；不承诺专业 ICC 色彩保真。
- WASM 被阻止时不下载额外兼容解码器；相关压缩图像的更多样例仍需专项验证。
- 合成离线测试不证明真实学校登录、CDN、课程文件或学校实际 CSP 全部兼容；原生 iframe 的 load 事件不等于已成功显示 PDF。
- 最终版真实管理器验证仅覆盖上述 Chrome / Tampermonkey 的手动新建安装和页面刷新；未覆盖 URL 安装、从 1.1.x 升级时的权限确认、自动更新或浏览器进程重启。Firefox 的测试仍为注入模式，不是 Firefox / Tampermonkey 的安装验证；Safari、Violentmonkey 等也不能据此宣称通过。
- 旧版 1.1.0 的真实管理器和手动升级记录见 [多格式验证记录](VALIDATION.md)，不能用作 1.2.0 的验收证据。
