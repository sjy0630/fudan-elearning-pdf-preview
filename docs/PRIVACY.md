# 隐私说明

复旦 eLearning PDF 预览是非官方、开源的浏览器扩展。我们不运行接收用户文件的服务器，不收集、出售或分享个人信息，不使用统计或广告服务。

- 扩展只在复旦 eLearning 页面识别用户点击的 PDF 文件链接。
- 用户打开文件时，扩展使用浏览器已有的登录状态向 eLearning 和其指定的文件服务器请求 PDF。扩展不读取或保存帐号密码，也没有 cookies API 权限。
- PDF 在当前浏览器内由随扩展打包的 PDF.js 渲染。不发送到其他预览、AI 或分析服务。点击下载按钮才会主动保存到磁盘；浏览器可能使用缓存。
- `webRequest` 权限用于识别用户正在打开的文件被重定向到哪个文件服务器，从而按需申请该域名权限。请求信息不上传、不记录到持久存储。
- 默认网站访问权限仅覆盖 `https://elearning.fudan.edu.cn/*`。可选的 HTTPS 权限仅在用户点击授权按钮时，为实际遇到的文件服务器逐个申请。不会默认获得所有网站的访问权限。
- 用户可在浏览器扩展设置中撤销可选权限或卸载扩展。扩展不维护用户数据库。

反馈渠道：[GitHub Issues](https://github.com/sjy0630/fudan-elearning-pdf-preview/issues)。请勿在公开反馈中上传私人课程资料、帐号密码或含授权参数的文件链接。
