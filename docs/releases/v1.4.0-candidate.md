# 1.4.0 PPT / PPTX 本地候选

日期：2026-10-29。油猴脚本和独立扩展同步更新，尚未推送 GitHub、发布 Release 或提交商店，也没有替换用户已安装的扩展。

## 功能

- 同时识别 `.pptx` 和 PowerPoint 97–2003 二进制 `.ppt`；不是通过修改后缀支持旧格式。
- 在本机后台解析，逐页显示文字、常见形状、内嵌图片和基本表格；提供前后翻页、页码跳转、缩放和适应窗口。
- 原文件上限 50 MiB、500 页；展开内容 150 MiB，单部件 50 MiB，XML/单页图形 8 MiB，ZIP 项数 10000；解析和单页处理 30 秒。
- 可取消、重试、打开原文件；结构与解析通过后启用原字节下载，后续显示失败不改变原始文件。
- 解析器、清理器和许可证随安装包分发，无运行时 CDN，不上传课件，不扩大默认访问权限。SVG 放入禁止脚本和网络访问的隔离页面。

## 兼容边界

预览为静态内容，不播放动画或音视频，不执行宏和嵌入对象，不读取外部图片或字体。不保证 PowerPoint 的字体、换行、复杂图形或排版完全一致。旧版矢量图片暂时省略并显示提示；栅格图片沿用 20 MiB、单边 16384、总像素 4000 万的限制，单页累计展示像素另有预算。加密、损坏和超限文件显示错误。

固定依赖为 MIT 的 `@web-ppt/core` 0.4.5。使用自己的 Worker 调用双格式核心，上游自带 Worker 仅支持 PPTX。构建时对固定版本修正旧 PPT 段落边界的字符样式游标，避免首字误用换段符颜色；补丁精确匹配，遇到引擎变更会停止构建，第三方声明记录该修改。

## 验证与样例

`tests/fixtures/presentation/normal.pptx` 是原创三页样例，含中文和英文、形状、PNG、基本表格；`normal.ppt` 是同一内容经 Microsoft PowerPoint 保存的真实 97–2003 文件。样例采用项目 MIT 许可，不包含课程资料。

`scripts/smoke-presentations.mjs` 在隔离 Chromium 和 Firefox 中检查两版真实界面：三页内容、图片、表格、翻页、跳页、缩放、适应窗口、原始文件字节、取消、重试、关闭和重开；同时拦截意外外部请求。详细本地报告在 `output/playwright/presentations-{chromium,firefox}/result.json`，截图保存在同目录。包完整性由 `npm run verify:packages` 核对。

本轮结果：完整 Node 测试 **256 / 256 通过**；Chromium **155.0.8059.12**、Firefox **156.0** 各 **5 / 5** 组界面检查通过，无意外外部请求或页面异常。两种安装包各 325 个资源的清单、校验和与重复打包一致性检查通过，生成脚本同步检查及语法检查通过。截图对照确认旧 PPT 段落首字颜色恢复，文字、图片、形状和表格可读。

## 构建产物

运行 `npm run build` 生成根目录 `elearning-pdf-preview.user.js`，以及 `dist/fudan-elearning-pdf-preview-chromium-1.4.0.zip`、`dist/fudan-elearning-pdf-preview-firefox-1.4.0.zip` 和校验文件 `dist/SHA256SUMS.txt`。Chrome/Edge 共用 Chromium 包；Firefox 包未签名，仅用于临时开发载入。帮助页内置两种格式的演示入口，无需学校账号。
